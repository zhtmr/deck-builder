5

토큰 검증은 세 단계로

auth/verify.ts
export async function verify(token: string) {  const cached = cache.get(token);  if (cached) return cached;   const claims = await jwt.verify(token, key);  if (claims.exp < Date.now() / 1000) throw new Expired();   cache.set(token, claims, TTL);  return claims;}
  • 먼저 로컬 캐시를 확인해요
  • 캐시에 없으면 서명과 만료를 검증해요
  • 통과한 결과를 TTL 과 함께 캐시해요
→ 키마다 하이라이트가 이동하고 오른쪽 설명이 따라옵니다.
6

캐시 한 겹으로 검증 비용을 줄였어요

auth/verify.ts
export async function verify(token) {  const claims = await db.findSession(token);  if (!claims) throw new Unauthorized();  return claims;}
  • 기존: 매 요청마다 DB 세션 조회
  • 조회 대신 서명 검증으로 교체
  • 결과를 캐시해 반복 검증 비용 제거
→ 키를 누르면 바뀌지 않은 줄은 미끄러지듯 이동하고, 새 줄만 반짝이며 나타나요.
